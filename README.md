# ミニカンファレンス用サンプルリポジトリ

## 概要
このリポジトリは、プログラミング初心者の大学生向けミニカンファレンス用リポジトリです。
実装するのは自己紹介用リンクページです。

## リポジトリ構成
本リポジトリの構成は以下の通りです。
```
src/
├── pages/
│   └── linkPage/
│       ├── linkPage.tsx
│       └── components/
│           ├── profile/
│           │   └── profile.tsx
│           └── ...
├── uis/
│   ├── avatar/
│   │   └── avatar.tsx
│   └── ...
└── App.tsx  // 本体（linkPage.tsx を配置するだけ）
```
